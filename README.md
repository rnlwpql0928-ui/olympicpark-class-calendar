# 공연 날, 내 수업은? (시연)

올림픽공원 공연 일정과 강좌 시간표를 대조해, 공연 날과 만나는 수업 회차를 회원에게는 내 수업 달력으로, 운영 부서에는 운영 화면으로 보여 주는 정적 웹 시연입니다.

- 회원 화면: https://rnlwpql0928-ui.github.io/olympicpark-class-calendar/
- 운영 화면: https://rnlwpql0928-ui.github.io/olympicpark-class-calendar/ops.html
